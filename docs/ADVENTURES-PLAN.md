# Новые форматы: рабочий контракт

Запрос: спроектировать и реализовать все 16 предложенных форматов, сохранив мышь, компактную сцену, обучение первого уровня и помощь по запросу. Существующие 9 игр и сохранения остаются.

| Формат | Главное действие | Доказательство решения |
|---|---|---|
| Детектив | Осмотреть улики, выбрать персонажа и доказательство | Подходят личность и подтверждающая улика |
| Эксперимент | Переключать рычаги, наблюдать механизм | Достигнуто заданное состояние выходов |
| Предсказание | Выбрать выход луча до запуска | Предсказание совпадает с симуляцией |
| Исправление программы | Изменить одну команду робота | Одна исправленная позиция, маршрут до цели |
| Программирование | Собрать команды и запустить робота | Допустимый маршрут до цели в лимит команд |
| Мини-побег | Найти код, открыть ящик, получить ключ | Дверь открыта найденным ключом |
| Песочные часы | Перевороты, ожидание события, начало и конец замера | Отмерен точный интервал |
| Лёд | Выбрать направление скольжения | Остановка на целевой клетке |
| Два героя | Одна команда двигает два связанных мира | Оба одновременно на своих целях |
| Ограниченное наблюдение | Выбрать информативные окна | Единственная модель по открытым сведениям |
| Обмен информацией | Выбрать вопросы свидетелям | Однозначно определён предмет |
| Обмены | Применять рецепты с реальным расходом предметов | Получен целевой предмет |
| Порядок событий | Переставлять события | Выполнены все явно показанные связи |
| Невозможный проект | Выбрать проект и нарушенное условие | Верны проект и причина |
| Один инструмент | Переносить и применять одну лестницу | Достигнута цель с повторным использованием инструмента |
| Своя загадка | Редактировать, проверить, сыграть, передать код | Редактор проверил решаемость, пользователь решил свою сцену |

В каждом формате три задания. Обучение показывается только на первом; ручная подсказка вычисляет осмысленное действие из позиции. Редактор действительно проверяет решаемость и экспортирует/импортирует код задачи, без имитации внешнего сервиса.

Владельцы: существующее общее состояние и сохранение; модуль новых сцен; один JSON с правилами и заданиями; общий рендер сцены/правого управления. Секреты и догадки не смешиваются: наблюдательные задачи засчитываются при достаточных данных, а не по счастливому попаданию.

Проверки: 48 новых решений через UI, отрицательные ответы, недопустимые действия, отмена там, где применима, старое сохранение, reload, offline, touch, узкие размеры и регрессия прежних игр. Это первоначальный контракт реализации. Последующим запросом разрешена публикация обновления в существующий публичный Git-репозиторий; хостинг отдельно не запрашивался.
