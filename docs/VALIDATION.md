# Проверки публикации

31 октября 2026 года. **`npm test` завершился успешно: десять браузерных наборов.** Проверена сборка 25 игр / 75 уровней и оглавление 46 задач: 25 доступны в игре, 21 остаётся предложением.

## Воспроизведение

```sh
npm ci
npx playwright install chromium
npm test
```

В этом прогоне использован установленный Chrome:

```sh
PLAYWRIGHT_EXECUTABLE_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm test
```

| Проверка | Подтверждённое поведение |
|---|---|
| `check-hints.cjs` | 24 уровня исходных игр через общую подсказку; карта 25 мест; сохранение прогресса. |
| `check-classics.cjs` | 12 уровней башни, кувшинов, моста и ламп; обучение, ошибки, лимиты и touch. |
| `check-tutorial.cjs` | Обучение кафе, сейфа, весов и переправы; следующие уровни без постоянной подсветки. |
| `check-catalog.cjs` | 46 описаний и стабильные статусы; оба атласа иконок; переходы и узкие экраны. |
| `check-warehouse.cjs` | Три склада; толчки, тупики, отмена и восстановление. |
| `check-undo.cjs` | Принадлежность истории, счётчики, восстановление победы/проигрыша и размер сохранений. |
| `check-adventures.cjs` | Все 48 новых заданий через UI; открытие уровней, сохранения и 25 мест на одном экране. |
| `check-adventure-errors.cjs` | Ошибочные доказательства, столкновения, часы, импорт/экспорт редактора и миграция. |
| `check-inline-recovery.cjs` | Упорядоченный запуск в изолированном iframe, старое сохранение восьми игр и отказ host API. |
| `check-life.cjs` | Огни, маршрут, движение, точность шага склада, отсутствие повторных наград, touch и reduced motion. |

24 исходных уровня + 3 склада + 48 новых заданий = 75 уникальных уровней. Набор классических игр дополнительно повторяет часть исходных уровней для ошибок и восстановления; это не ещё 12 уникальных уровней.

Карта проверена на ширинах 900/736/390/320 px: все 25 мест доступны сразу, области нажатия не пересекаются. Новые сцены проверены на горизонтальное переполнение на 736/390/320 px. Игровые проверки выполняются без сети. Касания и reduced motion проверены в эмуляции браузера.

## Документация и графика

Проверены 25 отдельных PNG размером 96×96, 25 строк оглавления README, стабильные якоря правил и локальные Markdown-ссылки. Все 25 рисунков различаются. Исходный атлас ImageGen сохранён; новый атлас и иконки локаций воспроизводятся из программной графики. В браузере проверена загрузка исходного атласа 1374×1145 и нового 384×384.

Скриншот README обновлён по текущей карте. Полный журнал, JSON-отчёты и снимки создаются в игнорируемом `test-results/`; пользовательские сохранения и credentials в Git не входят. GitHub Actions не добавлялись.

## Границы

Проверено в headless Chrome и его эмуляции touch. Отдельная приёмка физических телефонов, Safari/Firefox и человеческая оценка сложности не проводились. Проверка изолированного iframe не заменяет штатный показ внутри приложения Codex. Публичный Git поставляет исходники, документацию и готовые HTML; размещение игрового сайта является отдельным действием.
