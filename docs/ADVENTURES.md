# Приключения: 16 форматов, 48 заданий

Итоговая коллекция — 25 мест и 75 уровней. Все новые сцены запускаются с общей карты, первый уровень объясняется подсветкой, следующие открываются последовательно и остаются без автоматических инструкций. `?` хранит правила, «Подсказка» показывает полезное действие из текущего состояния.

Полные описания каждой задачи, её цель, правила, управление и названия уровней опубликованы в [оглавлении](CATALOG.md). Первоначальный контракт — [ADVENTURES-PLAN.md](ADVENTURES-PLAN.md).

## Что реализовано

| Сцена | Собственное поведение | Как проверяется решение / помощь |
|---|---|---|
| Детектив | Закрытые улики, персонажи, выбор доказательств | Пересечение выбранных осмотренных улик должно оставить единственного верного персонажа |
| Рычаги | Скрытые связи переключателей с лампами | Реальное XOR-преобразование; подсказка опирается на историю опытов, перебирает ещё не проверенные состояния |
| Прогноз | Отражение луча на видимом поле | Выход вычисляется трассировкой; выбор до запуска, путь показывается после проверки |
| Ремонт | Редактирование готовой программы робота | Нужны цель и ровно одна изменённая позиция; столкновение указывает команду |
| Робот | Очередь команд с ограничением длины | Пошаговая симуляция с остановкой у стены; BFS по доступным клеткам для помощи |
| Побег | Записка, предметы комнаты, цифры ящика, ключ, дверь | Сначала осмотр, затем код и получение ключа; без него выхода нет |
| Часы | Два независимых песочных часа, переворот, событие, начало/конец замера | Дискретная точная симуляция; BFS по остаткам и отмеренному интервалу |
| Лёд | Скольжение до стены | Засчитывается остановка на цели; BFS по достижимым остановкам |
| Двойники | Два поля, отражённые горизонтальные команды | Отдельные столкновения и совместная цель; BFS по паре положений |
| Окно | Ограниченные осмотры признаков скрытой комнаты | Ответ принимается только при единственном совместимом варианте; помощь выбирает различающий признак |
| Свидетели | Вопросы о цвете/месте первому свидетелю, форме второму | Полученные ответы сужают варианты; случайного правильного имени недостаточно |
| Обмены | Реальный расход и выдача предметов | Нельзя обменять отсутствующие ресурсы; BFS по инвентарю, отмена принятого обмена |
| События | Выбор двух карточек и перестановка | Проверяются все связи «раньше» и «непосредственно перед»; помощь перебирает допустимые порядки |
| Проекты | Выбор невозможного чертежа и причины | Проверки связности, пересечений и эйлерова пути; требуется верное обоснование |
| Лестница | Подход, установка, переход, снятие и перенос | Одна лестница в состоянии; поиск по позиции и месту установки, повторное использование на третьем уровне |
| Мастер | Редактирование, проверка, игра, экспорт и загрузка кода | GF(2) проверяет решаемость; пустое/нерешаемое поле и неподходящие коды отвергаются |

## Редактор своей задачи

Редактирование меняет клетки независимо. Проверка допускает только непустой решаемый узор. После «Играть» клетка переключает себя и ортогональных соседей. Все лампы должны погаснуть.

Код — JSON `{ "v": 1, "n": 2, "cells": [1,0,0,0] }`. Размер должен соответствовать открытому уровню (2, 3 или 4), длина массива — квадрату размера, значения — 0/1. Загрузка ограничена 4096 символами, проверяет структуру и решаемость до изменения сцены. Неудачная загрузка сохраняет текущее поле. Передача происходит копированием текста; приложение не заявляет автоматическое копирование в буфер или онлайн-публикацию задачи.

## Доказательства

Воспроизводимый запуск всех проверок:

```sh
PLAYWRIGHT_EXECUTABLE_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm test
```

`check-adventures.cjs` проходит все 48 новых заданий через настоящий UI, обучение или общую подсказку. Проверяет последовательное открытие, отсутствие автоматической помощи на старших уровнях, восстановление завершённых игр и 25 непересекающихся мест карты на экранах 900/736/390/320 px.

`check-adventure-errors.cjs` проверяет догадки без доказательств, бесполезное наблюдение, неверный выход луча, столкновения и длину программы, запертую дверь, неточный интервал часов, стену льда, отмену после reload, сохранение заработанного прогресса, проход без лестницы, ошибочное обоснование, порядок событий и настоящее редактирование/экспорт/импорт. Нерешаемая одиночная лампа 4×4 отклоняется. Старое сохранение девяти игр дополняется до 25 без потери положения башни. Все 16 сцен проверены на горизонтальное переполнение при 736/390/320 px, отдельно выполнен touch-проход льда.

Прежние шесть браузерных проверок также остаются в `npm test`. Игра и каталог проходят в режиме offline. Артефакты: `test-results/verification-adventures.json`, `verification-adventure-errors.json`, `adventure-*.png` (генерируются локально, не содержат пользовательских сохранений и не входят в Git).

Проверки выполнены в headless Chrome с эмуляцией touch. Физический телефон, Safari/Firefox и человеческая оценка сложности всех 75 заданий отдельно не проверены. Три ступени усложняют механику, но психологическая трудность не измерялась. Исходники и готовые автономные HTML поставляются через публичный Git-репозиторий. Размещение игрового сайта — отдельный шаг.
