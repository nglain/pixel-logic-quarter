# Иконки игровых локаций

25 PNG размером 96×96. Это исходные программные пиксельные рисунки из Canvas игровой карты; ImageGen-атлас `assets/catalog/puzzle-icons.png` при этом не изменяется. Идентификаторы файлов совпадают с адресами игровых сцен.

Пересборка из корня проекта:

```sh
python3 scripts/build.py
PLAYWRIGHT_EXECUTABLE_PATH=/path/to/chrome node scripts/build-doc-icons.cjs
python3 scripts/build-catalog.py
```

Браузер запускается с пустым сохранением и без сети. Скрипт рисует каждую локацию на прозрачном Canvas и записывает PNG; текст, пользовательский прогресс и интерфейс в иконки не попадают. README и текстовое оглавление ссылаются на эти файлы напрямую, поэтому изображения отображаются на GitHub без CSS и внешнего сервиса.
