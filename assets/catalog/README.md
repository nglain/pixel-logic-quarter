# Иконки оглавления

`puzzle-icons.png` — исходный пиксельный атлас, созданный встроенным ImageGen 31 октября 2026 года специально для оглавления проекта. Размер: 1374×1145 px, 6 колонок × 5 строк. Каждый символ занимает одну ячейку. Полный запрос — `prompt.txt`.

Порядок ячеек соответствует `icon` (0–29) в `src/catalog.json`, слева направо, сверху вниз. Положение вычисляется в CSS; изображение не разрезалось и не редактировалось после генерации. Обложки являются иллюстрациями задач, а не точным изображением игрового поля или правил.

Автономный `catalog.html` содержит атлас внутри себя. Исходный PNG сохраняется отдельно для редактирования и повторной сборки.
